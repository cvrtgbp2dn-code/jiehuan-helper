结账助手 · 帮助中心

离线项目记账工具：记单数与错单，自动算有效单数、人民币与美元，按归属人结清、一键导出 Excel。数据只存在本机，不联网、不上传。

快速开始

记一笔归属人（选填）+ 项目名 + 单数 / 错单，回车即记
批量导入粘贴群邀请消息 / 粘贴截图识别，都先出预览表核对再确认
汇总与导出勾选项目看汇总（只算未结清），一键导出 Excel

功能指引

录入与编辑

  • 双击单元格原地编辑项目名 / 归属人 / 单数 / 错单；回车确认、Esc 取消
  • 同名项目（同归属人）重复录入会先询问是否覆盖；错单大于单数会被拦下

拖动排序

  • 按住表格任意一行上下拖动即可调整顺序，蓝线显示插入位置
  • 拖动后自动切换成手动排序，表头上方出现「恢复默认排序」，点一下回到「最新在前」
  • 整行可拖，因此不能用鼠标拖选表格里的文字（双击编辑照常可用）

归属人与筛选

  • 归属人下拉只列有记录的归属人；侧栏按归属人筛选，「全部项目」在首行
  • 列表按最新记录在首行排序（日期倒序，同一天按录入先后）

结清与汇总

  • 汇总只算未结清；已结清行灰显，点状态列圆圈可恢复未结
  • 筛选某人后，汇总条右侧出现绿色「结清」按钮：勾选几笔就结清几笔；没勾选时显示「结清 0 笔」并置灰
  • 想结清该人全部未结账：先点「全选」（自动跳过已结清的行），再点结清
  • 已结清的行默认不勾选，全选也会跳过；仍可手动勾选（会提示「不计入汇总」）
  • 标记结清时会自动取消该行勾选

清空与撤销

  • 清空后 6 秒内可点提示条「撤销」；过期不可恢复，建议先导出 Excel 留底
  • 清空会连同归属人历史名单、输入框一起清空

群邀请消息识别规则（导入）

  • 一条邀请消息 = 一个项目，整段粘贴即可，可一次粘多条
  • 项目名：取第一个【】的内容（自动跳过「快手App」）
  • 单数：取「人数」行的数字
  • 错单：人数行以下各行末尾数字之和（如「日本1」「小孩4」→ 错单 5）；鼠标悬停错单单元格可看明细
  • 口令码、广告行自动忽略
  • 也支持普通格式：每行「项目名 单数 错单数」，空格 / Tab / 逗号分隔
  • 与已有项目（同归属人）同名时导入即覆盖，预览表标黄色「重复」提醒

单价与汇率（设置）

  • 「每单单价」决定有效单数换算的人民币；「汇率」决定美元金额（人民币 ÷ 汇率）
  • 改动只影响此后新记录，已记的账不会被追溯改写
  • 想改历史某笔：双击该行的单数 / 错单重新编辑即可

主题 / 字号 / 快捷键 / 托盘

  • 主题：亮色 / 暗色 / 跟随系统（跟随 Windows 设置自动切换）
  • 字号：小 / 中 / 大，整体等比缩放
  • 快捷键默认 Alt+Z：在任意软件里唤起本窗口，再按一次收回托盘。点设置里的快捷键按钮，直接按下新组合键即可改；冲突会提示并保留原键
  • 托盘：点关闭（X）会询问「最小化到托盘 / 退出应用」，可勾选记住；托盘图标单击唤回窗口，右键退出

软件更新

  • 软件会自动检查新版本并在有更新时弹窗提示；也可手动检查：设置 → 版本 → 「检查更新」
  • 点「立即更新」自动下载并重启生效；点「稍后」本次不再提醒该版本
  • 检查失败会静默忽略，不打断记账
  • 更新只替换程序文件，账目数据不受影响；若提示「安装目录不可写」，把软件移到桌面或文档目录再试

常见问题

  • 数据存在哪里？在 C:\Users\<你的用户名>\AppData\Roaming\结账助手，不在软件文件夹里。移动、改名、删除软件文件夹都不影响账目
  • 清空的数据能找回吗？只有 6 秒内「撤销」一条路，过期不可恢复
  • 已结清的钱去哪了？只是不再计入汇总，列表里仍在（灰显），导出 Excel 也包含，随时可恢复未结
  • 快捷键没反应？大概率被其他软件占用：设置时注册失败会提示并保留原键，启动时被占用也会弹提示；到 设置 → 快捷键 重设
  • 截图识别（OCR）不工作？不要移动或删除 resources\app.asar.unpacked 目录，识别引擎放在那里
  • 界面空白或报错？请运行 结账助手-win32-x64 目录里的 结账助手.exe，不要单独把 index.html 拖出来打开
