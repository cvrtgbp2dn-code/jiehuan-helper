结账助手 · 帮助中心

一个离线的项目记账工具：记单数与错单，自动算有效单数、人民币与美元，按归属人结清、一键导出 Excel。数据只存在你自己这台电脑，不联网、不上传，同事之间互不同步。

快速开始

记一笔归属人（选填）+ 项目名 + 单数 / 错单，回车即记；预览行实时显示有效单数与金额
批量导入粘贴群邀请消息 / 拖入 txt、Excel / 粘贴截图 OCR，都先出预览表核对再确认
汇总与导出勾选项目看汇总（只算未结清），一键导出 Excel；筛选某人后只导某人

功能指引

录入与编辑

  • 双击单元格原地编辑项目名 / 归属人 / 单数 / 错单，编辑时表格不位移；回车确认、Esc 取消
  • 同名项目（同归属人）重复录入会先询问是否覆盖；错单大于单数会被拦下

拖动排序

  • 按住表格任意一行上下拖动即可调整顺序，蓝线显示插入位置；松手后立即生效
  • 拖动后会自动切换成手动排序，表头上方出现「恢复默认排序」，点一下即回到「最新在前」
  • 手动排序下新记的账仍在最上面；筛选某人时拖动，只影响该范围内的先后，其他人不受影响
  • 注意：整行可拖，因此不能用鼠标拖选表格里的文字（双击编辑照常可用）

归属人与筛选

  • 归属人输入框下拉只列有记录的归属人；侧栏按归属人筛选，「全部项目」在首行
  • 列表按最新记录在首行排序（日期倒序，同一天按录入先后）

结清与汇总

  • 汇总只算未结清；已结清行灰显，点状态列圆圈可恢复未结
  • 筛选某个归属人后，汇总条右侧出现绿色「结清」按钮：勾选几笔就显示几笔、只结清这几笔；没勾选时显示「结清 0 笔」并置灰不可点
  • 想一次结清该人全部未结账：先点列表左上角「全选」（会自动跳过已结清的行），再点结清

勾选规则

  • 已结清的账默认不勾选，点「全选」也会自动跳过已结清的行
  • 仍可手动勾选已结清的行（会提示「该行已结清，不计入汇总」）；单独导出已结清单据时就靠它
  • 标记结清时会自动取消该行勾选，避免残留

清空与撤销

  • 清空后 6 秒内可点提示条「撤销」恢复；过期不可恢复，建议先导出 Excel 留底再清空
  • 清空会连同归属人历史名单、归属人输入框一起清空，不留残留

群邀请消息识别规则（导入）

一条邀请消息 = 一个项目，直接整段粘贴即可，可一次粘多条。
  • 项目名：取消息里第一个【】的内容（自动跳过「快手App」）
  • 单数：取「人数」行的数字
  • 错单：人数行以下各行末尾数字之和（如「日本1」「小孩4」→ 错单 5）；这些行会记为错单明细，鼠标悬停错单单元格可查看
  • 口令码、广告行自动忽略
  • 也支持普通格式：每行「项目名 单数 错单数」，空格 / Tab / 逗号分隔；只写项目名则单数记 0，导入后再改
  • 与已有项目（同归属人）同名时导入即覆盖旧单数，预览表会标黄色「重复」提醒

单价与汇率（设置）

  • 「每单单价 ¥」决定有效单数换算成人民币的金额；「汇率 1 美元 =」决定美元金额（人民币 ÷ 汇率）
  • 改动只影响此后新记录，已记的账沿用记账当时的单价与汇率，不会被追溯改写
  • 想改历史某一笔的金额：双击该行的单数 / 错单重新编辑即可（金额按该笔单价重算）

主题 / 字号 / 快捷键 / 托盘

  • 主题：亮色 / 暗色 / 跟随系统。「跟随系统」= 按 Windows 的浅色/深色设置自动切换，系统改主题时本软件实时跟随
  • 字号：小 / 中 / 大，整体等比缩放（等同浏览器缩放，不会打乱表格列对齐）
  • 全局快捷键默认 Alt+Z：在任意软件里唤起本窗口，再按一次收进托盘。点设置里的快捷键按钮，直接按下新组合键即可改，按键过程实时回显；与别的软件冲突会自动提醒并保留原键。点「恢复默认」可还原为 Alt+Z
  • 点关闭（X）会询问「最小化到托盘 / 退出应用」，可勾选记住选择；托盘图标单击即唤回窗口，右键可退出

拖动排序 / 勾选规则在哪里看

软件界面上只保留简短操作提示（例如表头上方的「按住行可拖动排序」），具体规则与说明都集中在本帮助中心，见上文「拖动排序」「结清与汇总」「勾选规则」小节。

软件更新

软件会自动检查新版本并在有更新时主动弹窗提示（只读取一个版本号，不上传任何账目数据）。也可以随时手动检查：设置 → 版本 → 「检查更新」。
  • 什么时候会自动检查？启动软件后 4 秒检查一次；之后每 6 小时一次；把软件从托盘唤回、或切回本窗口时也会检查（30 分钟内不会重复联网，很省流量）
  • 发现新版本会主动弹窗，显示版本号与更新内容，点「立即更新」自动下载并重启生效
  • 点「稍后」则本次使用期间不再自动弹窗提醒该版本（下次打开软件仍会提醒；想立刻更新随时可到设置里手动检查）
  • 网络不通或检查失败会静默忽略，不会打断正常记账
  • 日常更新只下载约 110KB 的增量包（界面与逻辑部分），不需要重新传整个软件包
  • 下载失败或想手动安装：点弹窗里的「下载完整安装包」，会用系统浏览器打开永久下载链接（永远指向最新版）
  • 更新只替换程序文件，账目数据存在 AppData 里，不受影响；若提示「安装目录不可写」，把软件移到桌面或文档目录再更新

把软件发给别人 / 复制下载链接

设置 → 安装包 → 「复制下载链接」，会复制一条永久有效的直达下载链接，粘贴到微信、邮件里发给对方，对方用浏览器打开即可下载最新版完整包。
  • 这是一条永久链接：以后不管更新到 v5.4、v5.5 还是 v6.0，链接一个字都不用改，始终下载到最新版，发过一次可以一直用
  • 适合发给新同事（第一次使用），或还在用旧版本、需要一次性升级的同事
  • 已经在用 v5.3 及以后版本的同事不需要发链接，软件会自己提示更新

常见问题

  • 数据存在哪里？在 C:\Users\<你的用户名>\AppData\Roaming\结账助手，不在软件文件夹里。移动、改名、删除软件文件夹都不影响账目
  • 清空的数据能找回吗？只有 6 秒内「撤销」一条路，过期不可恢复
  • 已结清的钱去哪了？只是不再计入汇总，列表里仍在（灰显），导出 Excel 也包含，随时可恢复未结
  • 快捷键没反应？大概率被其他软件占用：设置时注册失败会提示并保留原键，启动时被占用也会弹提示；到 设置 → 快捷键 重设
  • 截图识别（OCR）不工作？不要移动或删除 resources\app.asar.unpacked 目录，识别引擎放在那里
  • 界面空白或报错？请运行 结账助手-win32-x64 目录里的 结账助手.exe，不要单独把 index.html 拖出来打开
