# 结账助手 · 版本更新操作手册

> 配置已经全部做完了。以后你只需要**改需求 → 双击一个文件**，同事那边就能收到更新。

---

## 一、日常更新：只需两步

### 第 1 步：告诉 WorkBuddy 要改什么

比如说「把汇总卡片加个导出按钮」「修复筛选后数字不对的问题」。

改完后，**把这次更新的要点告诉它**（会显示在同事的更新弹窗里），例如：

> 更新说明写：新增导出按钮、修复筛选数字问题

### 第 2 步：双击运行

打开文件夹 `E:\WorkBuddy\结账助手v5\_release\`，双击 **`发布.bat`**。

等它跑完（约 1～2 分钟），会看到：

```
✓ 已生成 ...\resources\app.asar
✓ 增量包 _release/out/app.asar（约 115 KB）
✓ 版本文件 .../version.json
✓ 完整安装包 ...（161.7 MB）
== 1. 创建 Release v5.3.1 ==
== 2. 上传附件 ==
   ↑ app.asar（0.1 MB）... ✓
== 3. 更新仓库文件 ==
   ✓ version.json
   ...
✅ 发布完成
```

**看到「✅ 发布完成」就结束了。** 同事下次打开软件就会收到更新提示。

## 二、需要发给同事完整包的情况

只有两种：

| 情况                 | 怎么做                      |
| ------------------ | ------------------------ |
| **新同事第一次用**        | 把下面的**下载页面**或**永久链接**发给他 |
| **同事还在用 v5.2 或更早** | 同上，下载完整包升级一次后就自动了        |

**已经在用 v5.3 及以后的同事，什么都不用发**，软件会自己提示更新。

### 🌐 下载页面（发给同事看这个）

```
https://github.com/cvrtgbp2dn-code/jiehuan-helper
```

同事点开就能看到**软件介绍、界面截图、功能介绍和一个绿色的下载按钮**，  
点按钮直接下载最新版，不需要懂 GitHub。

**页面上有什么**：软件介绍、主界面截图、功能表格、安装步骤、常见问题（数据存哪、  
要不要联网等）、更新日志。这些内容都在项目根目录的 `README.md` 里，  
想改文案就直接改这个文件，或者让 WorkBuddy 改。

### 🔗 永久直达下载链接（一按即下）

```
https://github.com/cvrtgbp2dn-code/jiehuan-helper/releases/latest/download/checkout-helper-win32-x64.zip
```

**这个链接永远有效，永远是最新版**——不管以后更新到 5.5、5.6 还是 6.0，  
链接一个字都不用改，发过一次就可以一直用。

**最省事的用法**：打开软件 → 设置 → **安装包 → 「复制下载链接」**，一键复制，  
直接粘到微信 / 邮件里发出去即可（v5.4 起支持）。

> 💡 微信里发链接要点「复制链接」，对方用浏览器打开就能下载。  
> 也可以做成短一点的：搜「短链接生成」，把长链接粘进去即可。

## 三、版本号怎么改

改 `_build/package.json` 里的 `"version"`，例如 `5.3.0` → `5.3.1`。

> 直接跟 WorkBuddy 说「版本提到 5.3.1」即可，它会改。  
> **版本号必须比上一版大**，否则同事收不到更新提示。

## 四、需要修改更新说明时

编辑 `_release/notes.txt`。规则很简单：

- 每行以 `- ` 开头 = 一条更新说明
- 其他行（如注释、模板）会被自动忽略

```
# 这些注释不会显示
- 新增导出按钮
- 修复筛选后数字不对的问题
```

## 也可以直接让 WorkBuddy 帮你改。

## 五、原理速览（了解即可，不用操作）

```
你的电脑                          同事的电脑
─────────                        ─────────
改代码 → 双击 发布.bat            打开软件（自动检查）
   ↓                               ↓
打包 + 自动上传 GitHub            发现有新版本 → 弹窗提示
   ↓                               ↓
更新 version.json                 点「立即更新」
                                   ↓
                                下载约 115KB → 重启生效 ✅
```

**几个关键事实：**

- **日常更新只下载约 115KB**，不是 162MB。因为 162MB 里绝大部分是引擎和识别词库，永远不会变；每次改的只是界面和逻辑。
- **检查更新绝不发送任何数据**，只下载一个版本号文件。
- **账目数据存在 `C:\Users\<用户名>\AppData\Roaming\结账助手`**，不在软件目录，更新只换程序文件，数据完全不受影响。
- 更新源有**三个地址自动回退**（GitHub API 主源 + jsDelivr + 官方），哪个通用哪个。

## 六、出问题了怎么办

| 现象                     | 原因与处理                                      |
| ---------------------- | ------------------------------------------ |
| 双击 `发布.bat` 报「安装目录不可写」 | 软件正在运行。**完全退出软件**（含托盘图标）再重试                |
| 同事没收到更新提示              | 检查 1：版本号是否比原来大？检查 2：`发布.bat` 是否跑到「✅ 发布完成」？ |
| 同事点更新后下载失败             | 网络问题。让他稍后重试，或直接发完整包给他                      |
| 提示「尚未配置更新源」            | 配置文件出问题了，找 WorkBuddy 处理                    |
| 想彻底关掉自动检查              | 找 WorkBuddy，可以改成只保留手动检查                    |
