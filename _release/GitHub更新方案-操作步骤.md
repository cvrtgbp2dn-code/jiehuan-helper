# 结账助手 · 自动更新配置步骤（GitHub 免费方案）

做完这一套之后，同事就**不用再接收压缩包**了：软件里点「检查更新」→ 自动下载约 100KB → 重启生效。  
全程免费，不需要服务器、不需要买域名、不需要写代码。

一共 4 件事，大约 20 分钟。

---

## 〇、先看懂原理（30 秒）

```
你的电脑                          同事的电脑
─────────                        ─────────
改代码 → 运行发布脚本            打开软件
   ↓                               ↓
产出 2 个文件                     点「检查更新」
   ↓                               ↓
上传到 GitHub  ────────────────→  读取 version.json 得知有新版
                                    ↓
                                 自动下载 app.asar（约 100KB）
                                    ↓
                                 重启，更新完成 ✅
```

**两个关键概念：**

| 名词                 | 是什么           | 放哪       |
| ------------------ | ------------- | -------- |
| **仓库（Repository）** | 存代码的地方，像共享文件夹 | GitHub 上 |
| **Release（发行版）**   | 放安装包的地方，像附件柜  | 挂在仓库下面   |

**为什么要分两处？** GitHub 规定单个文件超过 100MB 不能放进仓库代码里，你的安装包有 162MB，所以必须走 Release 附件（那里单个文件可以到 2GB）。

**为什么日常更新只要 100KB？** 你的软件里，162MB 的绝大部分是 Electron 引擎和 OCR 词库——**这些东西几乎永远不会变**。每次改的只是界面和逻辑（约 111KB），放在 `app.asar` 里。所以日常更新只传这 111KB。

## 一、注册 GitHub

1. 打开 <https://github.com/signup>
2. 填邮箱 → 设密码 → 起用户名（**记住这个用户名，后面要用**）
3. 邮箱收验证码 → 验证
4. 完成。全程免费，**不需要实名认证**（这点和 Gitee 不同，Gitee 要传身份证）

> 建议用户名用英文小写，例如 `zhangsan`。

---

## 二、创建仓库并上传源码

1. 登录后点右上角 **`+` → New repository**
2. 填写：
   - **Repository name**：`jiehuan-helper`（随便起，记住它）
   - **Public** ← **必须选公开**，否则同事的软件读不到更新信息
   - **不要**勾选 "Add a README file"
3. 点 **Create repository**
4. 新页面点 **uploading an existing file**（或 `Add file → Upload files`）
5. 把下面这些**文件/文件夹**拖进去：

```
需要上传：
  src/                       ← 整个文件夹（界面源码）
  _release/                  ← 整个文件夹（发布脚本）
  _build/index.html
  _build/help.html
  _build/main.js
  _build/preload.js
  _build/package.json
  _build/tray.png
  .gitignore
```

> ⚠️ **不要上传**：`_build/node_modules/`（398MB）、`_build/lib/`（27MB）、`结账助手-win32-x64/`、任何 `.zip`。  
> 这些在 `.gitignore` 里已经排除了。如果拖错了，GitHub 会报"文件过大"。

1. 底部 **Commit changes** 提交

---

## 三、发布第一个版本（v5.3.0）

1. 回到仓库首页，点右侧 **Releases → Create a new release**
2. **Choose a tag** 输入 `v5.3.0` → 点 **Create new tag**
3. **Release title** 填 `v5.3.0`
4. **Describe this release** 写更新内容（例如"新增表格拖拽排序、检查更新功能"）
5. 拖入这两个文件（在你自己电脑的 `_release/out/` 里）：
   - `app.asar`（111KB，增量包，**必须有**）
   - `checkout-helper-5.3.0-win32-x64.zip`（162MB，完整包，建议也传，下载失败时可兜底）
6. 点 **Publish release**

---

## 四、提交 version.json

这个文件决定"同事的软件去哪里查最新版本号"。

1. 回到仓库首页 → **Add file → Create new file**
2. 文件名填 `version.json`
3. 内容：把你自己电脑 **项目根目录** 的 `version.json` 内容整个复制粘贴进去
4. 拉到下面点 **Commit new file**

提交后，这个地址就是同事软件的检查入口：

```
https://raw.githubusercontent.com/你的用户名/jiehuan-helper/main/version.json
```

## 五、把地址告诉我，完成最后一步

把上面那个地址发给我（或者只发你的**用户名**和**仓库名**），我会：

1. 把它写进软件的更新源
2. 重新打包
3. 给你最终的 v5.3 安装包

之后同事装的版本就能自动检查更新了。

---

## 六、验证是否成功

在软件里点：**设置 → 版本 → 「检查更新」**

- 显示「已是最新版本 v5.3.0」→ ✅ 配置成功
- 显示「尚未配置更新源」→ 更新源还没写进去，找我处理
- 显示「网络不可用」→ 检查网络，或 GitHub 被墙（换手机热点试试）

## 七、以后每次优化后怎么做（3 步）

```
第 1 步：让我改代码（你只要说需求）

第 2 步：双击运行  _release\发布.bat
         → 自动产出 app.asar + version.json + 完整包

第 3 步：上传到 GitHub
         a. 仓库 → Releases → Draft a new release
            Tag 填 v5.3.1（比上一版大）
            拖入 _release/out/app.asar
            Publish release
         b. 仓库 → 点开 version.json → 右上角铅笔图标
            把项目根目录 version.json 的新内容粘贴进去 → Commit
```

同事下次打开软件就会收到更新提示。

## 常见问题

**Q：同事的软件为什么没提示更新？**  
A：三个可能——① `version.json` 没更新（第八节第 3.b 步别忘）；② 版本号没变大；③ 同事的软件版本太老（v5.2 及更早的版本还没有更新功能，需要先传一次完整包）。

**Q：更新会丢账目数据吗？**  
A：不会。账目存在 `C:\Users\<用户名>\AppData\Roaming\结账助手`，**不在软件目录里**，更新只替换程序文件。

**Q：GitHub 在国内打不开/很慢怎么办？**  
A：检查更新只读一个小文件，通常没问题。若确实被墙，可以：① 让我把下载地址换成网盘链接（改一行配置即可，不用改代码）；② 或改用 Gitee（需实名认证，且附件限 100MB，要分卷，比较麻烦）。

**Q：软件会不会偷偷上传我的账目？**  
A：不会。更新功能只做两件事：下载 `version.json`（读版本号）、下载 `app.asar`（程序文件）。**从不发送任何本地数据**。

**Q：不想让它联网？**  
A：可以。告诉我，我把启动自动检查关掉，只保留手动「检查更新」按钮。

**Q：旧版同事怎么升级到 5.3？**  
A：**需要传一次完整包**（`结账助手-win32-x64-v5.3.zip`）。因为他们现在的软件里还没有 `update.bat` 这个更新助手。从 5.3 开始往后就都能自动更新了。

**Q：一定要传那个 162MB 的完整包吗？**  
A：不是必须。完整包只在两种情况有用：① 新同事第一次安装；② 更新下载失败时的兜底。日常只需要传 111KB 的 `app.asar`。

## 附：文件对照表

| 文件                        | 是什么             | 放哪                |
| ------------------------- | --------------- | ----------------- |
| `_release/out/app.asar`   | 增量更新包（111KB）    | **每次**上传到 Release |
| `结账助手-win32-x64-v5.3.zip` | 完整安装包（162MB）    | 给新同事 / Release 兜底 |
| `version.json`            | 版本号说明文件         | 仓库根目录，**每次**更新    |
| `_release/config.json`    | 你的用户名/仓库名（只填一次） | 只放自己电脑，别上传        |
| `_release/发布.bat`         | 一键打包脚本          | 只放自己电脑            |
